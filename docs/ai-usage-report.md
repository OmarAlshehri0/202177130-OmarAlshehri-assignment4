# AI Usage Report

## Tools Used and Use Cases
### ChatGPT / claude/ Gemini
I used AI support to help in the final Assignment 4 portfolio website. 
The main uses:
- organizing the project structure
- improve the pixel-art design direction
- reviewing JavaScript logic for navigation and form validation
- improving the README and other documents  

## Benefits and Challenges
### Benefits
- It gave me suggestions for better structure and interaction design.
- It helped me improve the quality of the documentation and make the project feel more professional

### Challenges
- Some design ideas from AI needed adjustment to better match my personal style
- AI-generated wording sometimes sounded too generic, so I rewrote parts of it to fit my own project voice.

## Learning Outcomes
By using AI in this assignment
I learned:
- how to translate a visual concept into a structured front-end layout
- how to create a stronger design system using typography and reusable UI patterns

## Responsible Use and Modifications
I did not submit AI output without review. I carefully checked the ideas and modified them to match my coding style and assignment requirements

I made sure to:
- review the structure and wording before using it
- test the JavaScript behavior manually
