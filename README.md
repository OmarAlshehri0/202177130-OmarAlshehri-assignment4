# 202177130-OmarAlshehri-assignment4

## Project Overview
This project is my final personal web application for Assignment 4. It is a one-page portfolio website designed in a retro RPG pixel-art style and built to present my profile, selected web projects, and contact information in a polished and creative way.

The website includes:
- An About section retro game-inspired landing section with my name, introduction, and social links
- A Projects section organized as a quest log with websites, games, and systems categories
- A featured card for my personal project, VelonWeb
- A My GitHub Projects section fro my githup projects 
- A responsive contact form with validation and helpful feedback

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub API

## AI Tools Summary
AI tools were used for:
- improving wording for project and documentation text
- change some of the retro RPG visual direction
- reviewing interaction 

## How to Run Locally
1. Clone the repository:
    git clone https://github.com/OmarAlshehri0/202177130-OmarAlshehri-assignment4.git
2. Open the project folder:
    cd 202177130-OmarAlshehri-assignment4
3. Open index.html in your browser.
